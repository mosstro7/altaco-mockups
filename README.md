## Notas

- Es un **mockup estático** (HTML + CSS + un poco de JS para el carrusel), exportado desde Claude Design. No es todavía el sitio Laravel.
- Los links del menú y de las tarjetas todavía no llevan a ningún lado.
- Teléfono, mail e Instagram del pie son **datos de ejemplo**.
- Paleta y tipografías: Playfair Display (títulos) + Inter (texto), tonos madera tomados del logo y el taller.
